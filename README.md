# Mis proyectos

Repositorio general con una selección de proyectos web y aplicaciones que desarrollé.

## Proyectos

### Barbería

Sitio web para una barbería con catálogo, reservas, registro e inicio de sesión, panel administrativo y conexión a MySQL.

- Tecnologías: HTML, JavaScript, PHP y MySQL.
- Carpeta: [`barberia.p2`](./barberia.p2/)
- Entrada principal: [`barberia.p2/index.html`](./barberia.p2/index.html)

### Libertad y Cambio

Sitio institucional para una agrupación universitaria, con aula virtual, biblioteca, padrón electoral, panel administrativo y soporte como aplicación web progresiva (PWA).

- Tecnologías: HTML, CSS y JavaScript.
- Carpeta: [`Facu. Derecho`](./Facu.%20Derecho/)
- Entrada principal: [`Facu. Derecho/index.html`](./Facu.%20Derecho/index.html)

El padrón real se mantiene fuera de Git porque contiene datos personales. padron.example.csv documenta el formato esperado.

### The Programming Studio

Landing page de un estudio de desarrollo web y sistemas.

- Tecnologías: HTML, CSS y JavaScript.
- Carpeta: [`theprogrammingstudio`](./theprogrammingstudio/)
- Entrada principal: [`theprogrammingstudio/index.html`](./theprogrammingstudio/index.html)

### TrackFit

Aplicación de seguimiento de entrenamiento, nutrición, hábitos, objetivos y logros, con servidor local y persistencia en SQLite o MySQL.

- Tecnologías: HTML, CSS, JavaScript, Python, SQLite y MySQL.
- Carpeta: [`Trackfit`](./Trackfit/)
- Entrada principal: [`Trackfit/index.html`](./Trackfit/index.html)
- Configuración de la base: [`Trackfit/database/README.md`](./Trackfit/database/README.md)
### PSP

Plataforma de gestión y venta de seguros con paneles para administración y vendedores, flujos de cotización, autenticación y persistencia mediante Supabase.

- Tecnologías: React, TypeScript, Next.js/Vinext, Supabase, Drizzle y Cloudflare.
- Carpeta: [`PSP`](./PSP/)
- Documentación: [`PSP/README.md`](./PSP/README.md)
- Interfaz independiente: [`PSP/live-server/index.html`](./PSP/live-server/index.html)

## Uso

Los proyectos puramente estáticos pueden abrirse desde su archivo `index.html`. Los proyectos con backend requieren configurar su servidor y base de datos localmente. Los datos de ejecución, contraseñas y archivos temporales no se incluyen en Git.
